# v0.0.16

## One sign-in

Install the plugin, run `/estelle:login`, and approve one page. That connects Estelle's tools and records your sessions, with no key and no second sign-in. Details: [capture-auth](../capture-auth.md).

Sign out with `/estelle:logout`.

## What is unchanged

- If you signed in through `/mcp`, your tools keep working. New sessions tell you they are not being recorded and to run `/estelle:login`.
- `ESTELLE_API_KEY` keeps working exactly as before and wins over this sign-in.
- The write warning from 0.0.15 still fires, including when the sign-in cannot be read.

## Limits

- Only Claude Code gets the one-step flow. Other hosts still use `ESTELLE_API_KEY` for tools.
- POSIX only. Windows reports `pending_unsupported_platform` and changes nothing.
- Signing out ends this plugin's grant on every machine for that account.
- After signing in, tools may need `/mcp` reconnect or a restart.

## On Codex, approve the hooks again

This release changes the plugin's files, so Codex asks again: run `/hooks` and press `t`, or choose **Trust all and continue**.
